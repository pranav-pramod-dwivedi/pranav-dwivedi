Small print.

This is a static personal site. It does not run analytics, advertising pixels or a comment system. There is no account, no newsletter form and no cookie banner because there are no cookies to manage.

What the site collects

Nothing directly. The pages are static files. If the site is hosted on a platform such as GitHub Pages or Cloudflare Pages, that provider may keep standard server logs such as IP address, user agent and request time for security and delivery. Those logs are controlled by the host, not by this site.

External links

Links to GitHub, RDCA, Destroyers CC, CricHeroes, Instagram and the legacy portfolio open other sites. Each of those sites has its own privacy policy and may set cookies or collect data after you leave this one.

  • External links open in a new tab where marked.
  • No affiliate or referral tracking is added to outbound links.
  • The site does not embed third-party video, ads or analytics.

Email

If you email hkdykk22@gmail.com, the message and address are used only to reply and continue the conversation. They are not added to a mailing list.

Legacy files

The old machine-readable files, including llms.txt and profile.json, remain on the previous domain until Stargaze Release 01. This page will be updated when they move.

Contact

Questions about this page can go to hkdykk22@gmail.com or through the contact page.

Retention & choices.

How long anything stays

This site keeps nothing on your device beyond normal browser storage for the page itself. Email is kept only as long as the conversation is useful. Host logs follow the host's retention schedule and are not copied into this project.

What you can ask for

If you have emailed me and want the thread removed, say so in a reply. There is no account, profile or mailing list to delete. You can also ask which links or files are current if you find an old copy of the site elsewhere.

Changes to this page

If the site starts using a form, analytics or embedded media, this page will say so before that change ships. The current build remains static and self-contained.

Scope of
this policy.

What this page covers and what it does not.

This policy covers the static pages served from this site. It does not cover external destinations such as GitHub, the cricket registries, Instagram or the legacy portfolio. Those sites have their own rules.

The short version is that the site is built to collect nothing directly. The longer version below explains the hosting, the email thread and the choices you still have.

Hosting.

The platform sees what any web server sees.

The site is served as static files. The hosting provider may keep standard request logs such as IP address, user agent and time for security and delivery. Those logs are controlled by the host, not by this project.

No analytics script is added to the page. No advertising pixel is loaded. No account is created when you visit.

Cookies.

There are none set by this site.

The site does not set cookies for analytics, advertising or personalisation. It does not run a cookie banner because there is no cookie to manage. A hosting provider may use its own security tooling, which is outside this project's control.

If a future build adds a form, embedded media or analytics, this page will be updated before that change ships.

Local
storage.

What stays in your browser.

The site may use normal browser behaviour to cache pages, fonts and images so the next visit is faster. That cache is controlled by your browser and can be cleared at any time.

There is no account, no saved profile and no newsletter state stored in the browser by this build.

Analytics.

No audience measurement is installed.

The site does not run Google Analytics, Plausible, Fathom or any other analytics package. There is no heatmap, session replay or advertising identifier. The absence is deliberate.

If that changes, the policy will name the tool, the data it receives and the way to opt out before the script is added.

Embedded
content.

No third-party frames on the page.

The site does not embed YouTube, Vimeo, Spotify, maps or social posts. Images and fonts are served locally. External links are ordinary links that open another site only when you choose them.

This keeps the page fast and avoids passing your visit to a third party before you have asked for it.

Email
retention.

The thread is the only record.

If you email hkdykk22@gmail.com, the message and address are used to reply and continue the conversation. They are not added to a mailing list and are not sold or shared for marketing.

Email is kept only as long as the conversation is useful. If you want the thread removed, say so in a reply and it will be deleted unless there is a legal or operational reason to keep it.

Your
choices.

The practical controls available to you.

  • Clear or block the browser cache at any time.
  • Use a private window if you do not want a local cache.
  • Ask for an email thread to be deleted after the conversation.
  • Use the contact page to ask which links or files are current.

Security.

A static site has a smaller surface, not no surface.

The site is served over HTTPS in production. External links are marked and open in a new tab where appropriate. No secret keys, private repositories or personal documents are served from the public pages.

The build is tested on current desktop browsers and an older Android Chrome. If you find a security issue, email the address on the contact page with enough detail to reproduce it.

Children.

The site is not directed at children.

This is a personal professional site. It is not designed for children and does not knowingly collect information from them. There is no account, chat or user-generated content on the site.

International
transfers.

Where the small amount of data may go.

The site itself does not transfer personal data. If you email, the message travels through your mail provider and Google's mail infrastructure. Those providers may process the message in a country other than yours.

The hosting provider may process request logs in its own regions. Those transfers are governed by the provider's terms, not by this page.
