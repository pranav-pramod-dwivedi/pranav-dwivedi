What probably
happened.

The ordinary reasons a route disappears.

01The URL changedThe page moved when the site moved from the old portfolio to this build.
02A typoA missing letter or an extra slash is enough to miss the route.
03An old linkA bookmark or an external page still points at the previous structure.
04It never existedThe address may have been guessed rather than copied from a real link.

Check the
URL.

The quick checks before you give up on the address.

  • The file name ends in .html, except for the home page.
  • There is no space or capital letter in the route.
  • The link starts with this site's domain, not the old one.
  • The page is not marked private or removed on purpose.
  • The route is listed on the Network page.

Use the
menu.

Every public route is one tap away.

The menu is the complete public navigation. It includes the home page, the photographs, About, Work, Stargaze, Cricket, Network and Contact. If a route is not there, it is not part of the current build.

The footer repeats the main routes and adds the external profiles. Either is a faster path than editing the address bar.

Old
links.

The previous site had a different structure.

The legacy portfolio used a flatter set of pages and machine-readable files. Some of those URLs still resolve on the old domain. If you arrived from a bookmark, the old page may be the thing that moved, not the record.

The Network page lists the legacy files that are still online. They will remain available until Stargaze Release 01 has its own public schema.

Report a
broken link.

A useful report includes the route you came from.

Send the address that failed and the page that sent you there. If the link came from an external site, include that page too. The fix may belong in the index rather than the destination.

Email hkdykk22@gmail.com with “Broken link” in the subject. A screenshot is optional. The URL is the important part.

A note on
the 404.

This page is part of the site, not a dead end.

A 404 is a routing failure, not a moral one. The useful response is to make the next step obvious: the menu, the main routes and a way to report the miss. That is what this page tries to do.

If you find a route that should exist and does not, the contact page is the right place to say so. The site is still small enough that a broken path can be fixed properly.
